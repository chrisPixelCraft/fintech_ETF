一次回答：文獻的波動標準化多尺度 MACD，能不能補充 Mom20 沒有的「趨勢強度與加減速」資訊？

- Production 完全不動，仍是 Mom20；只在分支 `claude/macd-tsmc` 研究
- 規則在跑任何 MACD 策略前寫死於本文件；正式策略只跑一次
- 凍結日期：2026-09-25

## 0. 定位與揭露

- **新的一次測試**：[Technical Momentum](technical_momentum_spec.md) 已測過 MACD 12/26/9 ÷ 價格（−0.36%）與 histogram 斜率（−1.18%），該假說依規則關閉
- 本研究是看過該結果後提出的；理由是改用 Baz et al.（2015）與 Deep Momentum Networks（Lim, Zohren, Roberts 2019）的訊號表示：
  - 波動標準化
  - 多尺度
- **不論結果，不會有第三次 MACD 測試**
- 2015–2026 全部已看過：retrospective causal test，不是 validation
- 只借訊號表示方式，不搬 LSTM、Sharpe loss、多空部位、波動目標

## 1. 訊號

`P` = 還原收盤價（action-neutral 報酬累乘）；EWMA 時間尺度 S 的平滑係數 α = 1 ÷ S（`adjust=False`）。

```text
MACD(S, L) = EWMA(P, S) − EWMA(P, L)
q          = MACD ÷ 近 63 日 P 的標準差
Y          = q ÷ 近 252 日 q 的標準差
尺度       = (8, 24)、(16, 48)、(32, 96)
MACD 分數  = 平均( rank(Y_快), rank(Y_中), rank(Y_慢) )     rank 在前 40 名內，缺值給 0.5
```

- 滾動視窗至少 80% 有值
- 市場資料從 **2013-01-01** 起（Y 需要約 1.3 年暖身）；評估期間仍為 2015-01 起

## 2. 策略結構

```text
150 檔 → Mom20 排名 → 前 40 名 → 依 MACD 分數重排 → 25 檔等權
```

- 前 40 名依 MACD 分數排最前面（同分時依 Mom20 順序）；第 41 名以後維持 Mom20 原順序
- 組合層與 production 相同：25 檔等權、投入 95%、續抱 35 名、換手門檻 10%、最後 3 天不交易
- 基準 Mom20 也用 2013 起的資料重跑（Mom20 只用近 20 日，結果應與 2014 起相同）

## 5. 通過條件（只套用在三尺度 MACD 重排）

| 條件 | 門檻 |
|---|---|
| 全期配對平均 Δ | > +0.5% |
| 95% bootstrap CI 下界 | > 0 |
| 中位數 Δ | ≥ 0 |
| 四段一致性（2015–18、2019–21、2022–24、2025–26） | 至少 3 段平均 Δ > 0 |
| 不靠大贏窗口 | 拿掉最大 3 個後 > +0.25% |
| 換手 | ≤ 1.5 倍 Mom20 |
| 成本 | 多出的成本 < 平均 Δ |
| 合規 | 失格、警告不增加 |

**診斷（只解釋）**
- 和 Mom20 的排名相關
- Mom20 最差 10 個窗口的 Δ
- 四段與成交價來源分段
