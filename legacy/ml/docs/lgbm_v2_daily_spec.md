# LightGBM-v2 每日排名 spec

**2015–2024 評估 STOP；後續應使用者要求加跑，未改判定。** Production 維持 Mom20；分支 `claude/lgbm-v2-daily`，2026-09-25 凍結。規則先於結果；原定評估一次、FAIL 即停。

## 1. 策略

每日 D−1 特徵 → LightGBM-v2 排名 → 共用組合層／Active Share／planner／D-Plan。無 gate；缺預測報錯，不 fallback Mom20。可排名池相同：近 20 日每日可交易。

Production 組合：前 25 等權、95% 投入、續抱 35 名、10% 換手門檻、末 3 天不交易。

## 2. v2-A 模型

沿用 [docs/hybrid_spec.md](hybrid_spec.md)：第 5 節全部特徵（無原始價格）；第 3、4 節資料／時點（2014 起、月營收次月 11 日、法人當日盤後）；第 6 節標籤／訓練。

未來 10 日原始報酬、學習率 0.005、Pearson 提早停止；C 方式先選樹數再以 100% 資料重訓。全域日曆每 5 交易日重訓，僅用前一日已確定標籤。與 Hybrid 唯一区別：非 panic 日亦須預測。

## 3. 期間與偏誤

| 期間 | 用途 |
|---|---|
| 2014 | 暖身 |
| 2015–2024 | 歷史評估，只跑一次 |
| 2025–2026/09 | 純測試：評估 PASS 後才跑，只跑一次，只報告 |

24 日窗、月初／月中，與 Mom20 配對；2015–2021 dev、2022–2024 validation。

預測僅用當時以前資料；但 2015–2024 已供 Hybrid 評估，約 23% panic 日表現已見，第二用法可能偏樂觀。2025–2026 未評估 LightGBM-v2，才是決定性純測試。

## 4. Gate

`Δ = R(LightGBM-v2 每日) − R(Mom20)`，逐窗配對：

| 條件 | 門檻 |
|---|---|
| 配對平均 Δ | > +0.5% |
| 配對中位數 Δ | ≥ 0 |
| 取消資格 | 不多於 Mom20 |
| 成本 | LightGBM-v2 成本 − Mom20 成本 < 平均 Δ |

全過 PASS 才跑 2025–2026 一次；任一未過 STOP、維持 Mom20。不調特徵／組合／標籤，FAIL 不換用法重試。

## 5. PASS 之後

2025–2026/09 純測試一次、只報告；仍有優勢才討論 shadow／production。

## 6. 事前風險

LightGBM 周轉較高：第一版約 6（Mom20 約 3.4），Hybrid 3.7 → 5.1。多出成本可能吃掉增益，按第 4 節判定，不放寬。

## 7. 修訂紀錄

2026-09-25：評估平均 Δ +0.23%（95% CI −0.24% ~ +0.68%），未達 +0.5%，判 STOP；應使用者要求仍跑 2025–2026/09，偏離第 4 節。標「STOP 後應要求執行」，不自動改 STOP。

仍每 5 交易日以 2014 起至前日全部確定標籤重訓。若依純測試改決定，2025–2026 不再乾淨。
