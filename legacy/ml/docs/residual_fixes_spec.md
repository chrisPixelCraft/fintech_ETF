## 2. 修正：各改一件事

原 residual：近 60 日 β = `cov(lr, lm) / var(lm)`；近 N 日 `resid = Σ (lr − β × lm)`，`lm` = 0050。

| 代號 | 修正 | 公式 |
|---|---|---|
| A `ew` | 市場基準換成 150 檔等權 | `lm_i(t)` = 當天有報酬的其他股票 `lr` 平均（不含股票 i） |
| B `industry` | 產業 residual | `lm_i(t)` = 同產業其他股票的 `lr` 平均；產業成員 < 3 檔時改用 A |
| C `shrink` | β 收縮 | `β* = 0.5 × β + 0.5`，基準仍為 0050 |

共通：N = 20、25；β 60 日；至少 80% 有值，缺值排名 0.5；可排名池同 Mom20。只用 D−1 以前報酬，等權／產業平均僅含當日有值者。

沿用 production：前 25 等權、95% 投入、續抱 35 名、10% 換手、末 3 天凍結。不測 residual ÷ 殘差波動：一般動能的 `risk_adjusted` 已 −0.83%。

產業來源：證交所 ISIN「產業別」（上市 `strMode=2`、上櫃 `strMode=4`），2026-09-25 抓取至 `data/momv2/industry.csv`；raw sha256：`industry_provenance.json`。150 檔全分類，12 產業有 ≥3 檔，其餘 16 檔用等權市場。現分類回套 2015 起有輕微 look-ahead，如 2023 新類別／公司改分類。
