# Hybrid spec：Panic 時改用 LightGBM-v2 排名

研究問題：Panic 時以 LightGBM-v2 取代 Mom20 排名，能否改善整體報酬？

Production 不動；Hybrid 僅用分支 `claude/hybrid`。規則先凍結，歷史評估僅一次，FAIL 即停。

2026-09-25 凍結；commit 後不改定義。唯一修訂（第 10 節）在結果前。

## 1. 結構

```text
D−1 → Panic gate ─ FALSE → Mom20 排名
                  └ TRUE  → LightGBM-v2 排名
                         ↓
    共用組合層、Active Share、planner、D-Plan
```

共用 production 組合：前 25 檔等權、投入 95%、續抱 35 名、換手門檻 10%、最後 3 天不交易。非 Panic 日等同 Mom20。

## 2. Panic gate

決策日 D 僅用 ≤D−1 的 0050 還原日報酬 `r`：

```text
R20(D−1)  = Π(1 + r) 近 20 日 − 1
vol20(t)  = std(log(1 + r)) 近 20 日（樣本標準差，20 日皆須有值）
threshold = median(vol20) 於資料起點至 D−1 的所有交易日
PANIC     = R20(D−1) < 0  且  vol20(D−1) > threshold
```

- vol20 歷史少於 250 日時 PANIC = FALSE
- 不掃門檻，不換市場代表

## 3. 期間

| 期間 | 用途 |
|---|---|
| 2014 | 資料起點：訓練、特徵與 gate 歷史的暖身 |
| 2015–2024 | 歷史 walk-forward 評估，只跑一次 |
| 2025–2026/09 | 純測試：評估 PASS 後才跑，只跑被選中的版本一次 |

各版資料自 2014-01-01 起（config `data.start`）。月初／月中起 24 交易日窗；2015–2021 用 dev、2022–2024 用 validation，依既有規則排除跨界窗。

150 檔為 2026 名單，早年存活偏誤較大；同池配對受影響較小。

## 5. LightGBM-v2 特徵

符號：`P` 為還原價格指數（`action_neutral_return` 累乘），`lr` 為日對數報酬，`m` 為 0050。逐股票、僅用 t 以前資料。

| 名稱 | 定義 |
|---|---|
| `r1` `r3` `r5` `r10` `r20` `r60` | `P(t) / P(t−k) − 1` |
| `r20_rank` | 當日 `r20` 的橫斷面百分位排名 |
| `beta60` | 近 60 日 `cov(lr, lr_m) / var(lr_m)` |
| `resid_mom60` | 近 60 日 `Σ(lr − beta60 × lr_m)` |
| `idio_vol60` | 近 60 日 `std(lr − beta60 × lr_m)` |
| `down_vol20` | 近 20 日 `sqrt(mean(min(lr, 0)²))` |
| `dd60` | `P(t) / max(P, 近 60 日) − 1` |
| `dist_high252` | `P(t) / max(P, 近 252 日) − 1` |
| `abn_volume` | 近 5 日平均成交量 ÷ 近 60 日平均成交量 |
| `liquidity` | `log(近 20 日平均 收盤 × 成交量)` |
| `breadth` | 當日 `r20 > 0` 的股票比例（全市場同值） |
| `dispersion` | 當日 `r20` 的橫斷面標準差（全市場同值） |
| `mkt_vol20` | 0050 的 vol20（全市場同值） |
| `rev_yoy` | 最新可用月營收 ÷ 報表上的去年同月 − 1 |
| `rev_mom` | 最新可用月營收 ÷ 報表上的上月 − 1 |
| `rev_yoy_acc` | `rev_yoy` − 前一個月的 `rev_yoy` |
| `rev_yoy_rank` | 當日 `rev_yoy` 的橫斷面百分位排名 |
| `rev_record` | 最新月營收 ≥ 前 12 個月最高者為 1，否則 0 |
| `rev_days` | t 距最新可用月營收公布日（次月 11 日）的日曆天數 |
| `foreign_5d` `foreign_20d` | 外資淨買超股數近 5／20 日合計 ÷ 近 20 日平均成交量 |
| `trust_5d` `trust_20d` | 投信淨買超股數近 5／20 日合計 ÷ 近 20 日平均成交量 |

可預測股票須當日可交易且 `r20` 有值（同 Mom20）；其他缺值由 LightGBM 處理。

## 6. 兩個版本

| 版本 | 特徵 |
|---|---|
| v2-A | 第 5 節全部 |
| v2-B | 第 5 節全部 ＋ `open` `high` `low` `close` `volume`（t 日原始數值） |

兩版訓練完全相同，沿用 `lgbm_strategy` 現有程式：

- 標籤：未來 10 日原始報酬（`raw_return`，標籤結束日 ≤ 訓練截止）
- 資料：2014-01-01 起所有已確定的標籤
- 切分：依時間前 80% 訓練、最近 20% 驗證，中間隔 10 日
- 模型：`model.PARAMS`，學習率 0.005，Pearson 提早停止
- C 方式：選好樹數後用 100% 資料重訓（`refit_on_all=True`）
- 重訓：全域日曆每 5 交易日；D 用最新重訓日 ≤ D 的模型，只訓練至重訓前一日

不再重測：相對強弱標籤、學習率、動能回看天數。

## 7. 通過條件

兩版各自和 Mom20 在 2015–2024 同一組窗口逐窗口配對，`Δ = R(Hybrid) − R(Mom20)`：

| 條件 | 門檻 |
|---|---|
| 配對平均 Δ | > +0.5% |
| 配對中位數 Δ | ≥ 0 |
| 取消資格 | 不多於 Mom20 |
| 成本 | Hybrid 成本 − Mom20 成本 < 平均 Δ |

選版規則：

| 結果 | 動作 |
|---|---|
| 兩版都通過 | 選平均 Δ 較高者 |
| 只有一版通過 | 用那版 |
| 都沒通過 | STOP，維持 Mom20 |

Panic 日 LightGBM − Mom20 僅診斷，不調特徵／門檻或挑模型；FAIL 後不刪特徵或換門檻重試。
