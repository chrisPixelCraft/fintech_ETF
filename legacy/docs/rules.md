# 規則與正式使用限制

**研究回放；正式提交仍為 `BLOCK_SUBMISSION`。** 原始依據：[official_docs](../../official_docs/)；缺主辦方證據即未通過。

## 回放中檢查的條件

| 項目 | 固定條件 |
|---|---|
| 初始本金 | TWD 10 億 |
| 持股檔數 | 20–30 |
| 一般單股上限 | NAV 10% |
| 台積電上限 | NAV 25% |
| 現金比例 | ≥0 且 <25% |
| 委託單位 | 1,000 股 |
| 買賣手續費 | 0.1425% |
| 賣出稅 | 0.3% |
| 訊號與定股數 | 前日已知資料 |
| 模擬成交 | 次交易日均價 |

帳面 NAV 與含股利歸屬的 `economic_nav` 分列；年度採後者，309.16% 對齊全期帳面報酬。帳本模擬整日回退、累積警告、三次失格及主動／被動超限；候選另須零原始超限日，不靠被動寬限。

±10% 價格保護僅為研究門檻。未成交、缺價、無有效計畫、超價格保護均使研究資格失敗，不能全算官方警告。

## 仍缺的官方證據

Active Share 缺逐日 ETF 持股、發布時間及算法；公司行動、零股、費用取整、警告回退順序仍缺平台契約。回測不能證明主辦方帳本、正式收件、策略一致性或行政資格。

`plan`、`research-plan` 均不輸出可提交政策。零回測警告僅支持指定輸入的已量測門檻，非全面合規；正式賽期漏交仍可能違規。
