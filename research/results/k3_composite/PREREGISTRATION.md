# K3 綜合版：動能＋投信＋營收（事前登記）

寫於 2026-10-25，候選回測結果產生之前。`strategies.py` 與本檔 SHA256 記在 `TASK_BRIEF.md`，跑完不改。

## 問題

- 627 隊、各組取前6，約前2%
- K2 大贏率 22.1%、大輸率 10.1%；K1 大贏率高但有警告、近期差
- 要回答：綜合訊號能否提高大贏機率，同時不增加大輸與警告

## 原始想法的問題 → v3.1 修正

| 問題 | 原因 | v3.1 做法 |
|---|---|---|
| 平均會稀釋極端值 | • 三個分數平均<br>• 選到「樣樣普通」的股票 | • 動能排序保留爆發力<br>• 投信、營收改當確認條件 |
| 動能崩跌 | • 純動能追到沒基本面的漲勢<br>• K1 近3期大輸 | • 只在投信買超 >0、營收 YoY >0 的股票中排動能 |
| K1 吃警告 | • 集中權重漂移過 10% | • 核心權重降到 8%<br>• 超過 9% 只賣不買修正 |
| 換手成本高 | • K1 每窗口換手 5.2 倍 | • 每5日才重排<br>• 續抱緩衝、換手 ≥10% 才換 |
| 大換倉被下單模組拒 | • 現金比例安全檢查 | • 保存目標，之後重試 |

依據：價格動能多半來自基本面動能（Chan, Jegadeesh & Lakonishok 1996；Novy-Marx 2015）；FinLab 實測投信買超需要營收確認才贏 0050。

K3.0（原始平均版）一起測，只作對照：兩版組合層完全相同，只差選股規則。

## 假設與替代解釋

- Hypothesis
	- 有確認的動能，保留動能的大贏、減少崩跌
- Prediction
	- K3.1 大贏率比 K2 高 ≥3pp，大輸率不高於 K2 +3pp，0 警告
- 最強替代解釋
	- 確認條件太寬，K3.1 只是 K1 換名字
	- 存活者偏誤讓集中版早年偏好
- 能降低的不確定性
	- 確認條件能否把 K1 的大輸壓到 K2 附近

## 策略（參數凍結）

共用：核心10檔各 8%、補位10檔各 1.5%、投入 95%；首日建倉；每5日或新月營收可用後重排；核心排名 ≤15、補位 ≤30 續抱；換手 ≥10% 才換；目標保存並在現金違規時重試；權重 >9% 只賣回 8%；最後3日不交易。

| 代號 | 選股排序 |
|---|---|
| K3.0 平均 | • 動能、投信10日買超／均量、營收 YoY 三者百分位平均 |
| K3.1 確認動能 | • 條件：投信10日買超 >0、營收 YoY >0<br>• 條件內依 Mom20 排序<br>• 不足20檔用 K3.0 分數補 |
| 對照 | K2、K1、T2、Mom20（沿用 conc_tournament 結果）；0050 |

窗口：與 conc_tournament 相同的 276 個歷史窗口＋近5期。

## 判斷規則（寫死，276 窗口）

Δ50 = 策略淨報酬 − 0050。

- G0 有效性
	- 0 失格；總警告日數 = 0
- G1 更會大贏
	- P(Δ50 ≥ +5pp) ≥ K2 + 3pp（≥ 25.1%）
	- 且 P(Δ50 ≥ +10pp) ≥ K2 + 2pp（≥ 7.8%）
- G2 大輸不明顯變多
	- P(Δ50 ≤ −5pp) ≤ K2 + 3pp（≤ 13.1%）
- G3 不靠單一時期
	- 4段中至少3段尾端差 > 0
- G4 近期沒壞掉
	- 近5期平均 Δ50 ≥ −2pp

結論：

- K3.1 通過 → 建議取代 K2，由使用者決定
- 只有 K3.0 通過 → 同上，改提 K3.0
- 兩者都過 → 尾端差較大者
- 都未通過 → 維持 K2；列出最接近者
- 不因結果新增候選、改參數或改門檻

只報告：P(Δ50 ≥ +15pp)、平均／中位 Δ50、勝率、回撤 P90、換手、費稅、K3.1 每次通過條件檔數、K1 警告窗口的警告原因（診斷）。
