## 結論先寫：要回答什麼

- 動能／投信／營收三個分數怎麼加權，大贏機率最高、大輸不變多
- DEV 選出的權重，在沒調過的 validation 期間能不能贏 K2

## 為什麼要切期間

- K3.0 的優勢來自 276 窗口全期；在同一份資料上挑權重，會挑到運氣
	- 前例：H1 在看過的期間 +1.78%，測試期 −2.15%
- 依使用者既有流程：DEV 調 → validation 一次 → 已用過的期間只報告

| 期間 | 窗口 | 用途 |
|---|---:|---|
| DEV 2015–2021 | 166 | 跑全部16組權重、選一組 |
| Validation 2022–2024 | 70 | 只跑選出的那組，判斷是否採用 |
| 2025–2026＋近5期 | 45 | 已用過，只報告 |

## 變數分類

| 角色 | 內容 | 處理 |
|---|---|---|
| 科學變數 | 權重 (動能, 投信, 營收) | • 單形格點，間距 0.25，15點<br>• 加上等權 (1/3,1/3,1/3) |
| 固定 | 組合層 | • 核心10檔各 8%<br>• 補位12檔各 1.25%（多留2檔緩衝） |
| 固定 | 調整規則 | • 同 K3：每5日重排、續抱緩衝、換手 ≥10%、>9% 只賣、最後3日不交易 |
| 無調參 | — | 組合層不調；結論只適用這個組合層 |

補位改12檔，是為了避開 K3.0 的「持股少於20檔」警告。

## DEV 選擇規則（寫死）

Δ50 = 策略淨報酬 − 0050；尾端差 = P(Δ50 ≥ +5pp) − P(Δ50 ≤ −5pp)。

- 候選資格
	- 0 失格；每窗口警告 ≤1 日；DEV 總警告 ≤2 日
- 平滑尾端差
	- 該點與相鄰格點（任一權重差 0.25）尾端差的平均
	- 用平均降低「挑到單一幸運點」的風險
- 選平滑尾端差最高者
	- 同分選 P(Δ50 ≥ +10pp) 較高者
	- 再同分選格點順序較前者
- 同時報告：是否落在邊界（某權重為 0 或 1）

## Validation 判斷規則（寫死，只看選出的那組）

對照 K2 在同一70窗口的結果。

- V1 尾端差 ≥ K2
- V2 P(Δ50 ≤ −5pp) ≤ K2 + 3pp
- V3 平均 Δ50 > 0
- V4 0 失格、0 警告

結論：

- 全過 → ADOPT：建議取代 K2，由使用者決定
- 未全過 → REJECT：維持 K2，不再調這組權重
- 不因結果改格點、改規則或改看哪個期間
