# 集中版：前6名錦標賽目標（事前登記）

寫於 2026-10-24，候選回測結果產生之前。`strategies.py` 與本檔 SHA256 記在 `TASK_BRIEF.md`，跑完不改。

## 問題

- 初賽各組取 NAV 前6名進複賽；進了複賽，初賽分幾乎拉不開
- 目標因此是「進前6的機率」，不是贏 0050 的平均或勝率
- 要回答：集中版是否提高「大幅超越 0050」的機率，且大幅落後的機率沒有更高

## 假設與替代解釋

- Hypothesis
	- 把訊號集中在10檔（各 8.5%），保留訊號期望值、放大報酬分布，提高大贏機率
- Prediction
	- 至少一個集中版的 P(Δ50 ≥ +5pp) 比 T2、Mom20 高至少 5pp，且 P(Δ50 ≥ +5pp) > P(Δ50 ≤ −5pp)
- 最強替代解釋
	- 集中只放大雜訊；大贏與大輸同步增加
	- 2026 名單股票池的存活者偏誤，會讓早年集中版看起來特別好
- 能降低的不確定性
	- 集中後尾端是否偏向有利的一側

## 期間

- 歷史：`competition.episodes.build_episodes`，dev／validation／holdout，月初＋月中，2015-01 起，共 276 個24日窗口
	- holdout（2025–2026-09）先前已用過；本次存取記入 `research/holdout_access_log.jsonl`
- 近5期：第二、三批的 W1–W5（2026-04-30 → 10-22）
- 窗口重疊（月初與月中），276 不是獨立樣本

## 策略（參數凍結）

| 代號 | 定義 | 調整 |
|---|---|---|
| K1 MomConc | • 核心：Mom20 分數前10，各 8.5%<br>• 補位：接下來10名，各 1% | • 每日判斷，換手 ≥10% 才調整<br>• 核心排名 ≤14、補位排名 ≤30 續抱 |
| K2 TrustRevConc | • 篩選：投信10日買超 >0、3月均營收創12月新高、YoY >20%<br>• 依投信10日買超／20日均量排序<br>• 前10為核心 8.5%，11–20為補位 1%，不足用大型股排名補 | • 首日建倉<br>• 新月營收可用後重篩，換手 ≥10% 才換 |
| T2 | 第三批 LargeTrust（共用資料面板，邏輯不變） | 同第三批 |
| Mom20 | 正式版 | 原設定 |
| 0050 | close-to-close 含權息 | 參考 |

共用：投入 95%、最後3日不交易、超過上限 −0.5pp 或現金違規才修正。

## 指標

Δ50 = 策略淨報酬 − 0050（同窗口、含費稅）。

- 大贏率 P(Δ50 ≥ +5pp)
- 大輸率 P(Δ50 ≤ −5pp)
- 尾端差 = 大贏率 − 大輸率
- 另報：平均、中位數 Δ50、勝率、P(Δ50 ≥ +10pp)、最大回撤 P90、警告日數

## 判斷規則（寫死，只用 276 窗口）

- G0 有效性
	- 0 失格；任一窗口警告日數 ≤1；總警告日數 ≤ Mom20
- G1 尾端偏向有利
	- 尾端差 > 0，且平均 Δ50 > 0
- G2 比對照更會大贏
	- 大贏率 ≥ max(T2, Mom20) 大贏率 + 5pp
- G3 不靠單一時期
	- 4段（2015–2018、2019–2021、2022–2024、2025–2026）中至少3段尾端差 > 0
- G4 近期沒壞掉
	- 近5期平均 Δ50 ≥ −2pp

結論：

- 通過 → 「錦標賽候選」，由使用者決定是否採用
- 多個通過 → 尾端差最大者
- 都未通過 → 不建議集中版；列出最接近者與失敗關卡
- 不因結果新增候選、改參數或改門檻

## 已知限制

- 存活者偏誤：股票池為 2026 名單，集中版受影響更大；早年結果偏樂觀
- 窗口重疊，信賴區間會偏窄
- 營收公布日一律假設 11 日
- K2 早年通過篩選的股票少，常由大型股補位
- 不知道其他隊伍的報酬分布，「大贏」只是前6名的代理指標
