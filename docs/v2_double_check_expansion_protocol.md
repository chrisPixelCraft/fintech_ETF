# v2 double-check：第二輪局部擴搜規格

本輪只擴大研究用選參範圍。正式 `plan` 仍為 `BLOCK_SUBMISSION`；Active Share、官方結算與平台收件等證據缺口，不能靠更多回測消除。逐條規則與未知項目見[規則表](v2_double_check_rules.md)。

## 要回答什麼

在完全沿用已稽核 v2 帳本、資料、費稅、委託公式及八項零計數門檻的條件下，檢查 `d0034` 附近較密的參數組合，能否取得更高的**開發期**帳面報酬。既有 `d0034` 是必須保留的比較基準；沒有合格新候選勝出，就維持原研究候選。

上一輪 836 組不同設定均在兩個股票池回放，官方事後股票池只有 4 組通過已量測門檻。`d0034` 在該池報酬為 286.50%、最大回撤為 29.83%；同一參數在歷史股票池報酬為 145.35%。這些數字來自[既有報告](../reports/v2_double_check_fintuned_report.md)，不是新一輪的結果。

## 搜尋範圍

以已稽核 `d0034` 的其餘參數為定值，下列六軸作完整局部網格。這是事前固定的 **576 個位置**，其中 3 個與舊 836 組的有效設定重複，故需新執行 **573 個不同候選 × 2 池＝1,146 次回放**。重複位置只引用原先已驗證的相同設定，不把舊結果算作新試驗。

| 參數軸 | 本輪取值 |
|---|---|
| `momentum_weight` | 0.35、0.45、0.55、0.65 |
| `long_return_fraction` | 0.1、0.2、0.3 |
| `volume_low` | 0.7、0.8、0.9 |
| `max_replacements_per_day` | 0、1 |
| `macd_tuple` | (8, 21, 5)、(12, 26, 9) |
| `volume_high` | 2.5、3、4、5 |

這些是策略參數，不是官方風控門檻。20–30 檔持股、單股權重、現金、整張、白名單、費稅與價格保護均不因調參放寬。576 只代表上表六軸的完整組合；上一輪的全域離散空間及連續參數仍未窮舉。設定及位置對照應由 [`config/v2_double_check_expansion.json`](../config/v2_double_check_expansion.json) 與擴搜輸出的 `grid.json` 保存。

## 選擇與驗證

每個新候選必須走同一帳本及獨立稽核，完成 417 個交易日、未失格、數值有限，且以下八個計數**逐項為零**：`raw_rule_breach_days`、`measured_hard_breach_days`、`no_valid_plan_days`、`unfilled_orders`、`simulated_warning_days`、`stale_held_price_days`、`hold_without_envelope_days`、`execution_price_bound_breaches`。缺值不可當作零。這沿用[前輪選參器](../src/double_check_tuning.py)，其中零原始超限和零價格保護超界是額外保守的研究門檻。

只用 `official_ex_post` 選擇：將新合格候選與舊 `d0034` 以帳面 NAV 總報酬排序，平手依序比較最大回撤、雙邊換手率、ID。獲選參數原樣重播 `historical_pit`；該池是敏感度檢查，不重新選第二個冠軍。若新候選沒有勝過 `d0034`，應明確記錄「未更新」，不得改成挑選不合格高報酬組合。

完整條件包括每個新組合兩池皆有終態、來源和設定 hash 不變、逐試驗帳本獨立核對、獲選組合重新回放與來源一致、結果摘要與帳本一致。失敗或中斷輸出不得參與排序；舊 836 組與既有報告保持原狀。新資料放在獨立的 [`outputs/v2_double_check_expansion`](../outputs/v2_double_check_expansion/)，不能覆蓋舊試驗。

## 如何解讀結果

兩個股票池的 2025-01-02～2026-09-21 行情均已參與開發。`official_ex_post` 把 2026 年公布的 150 檔名單用於 2025 年，含成分股前視偏誤；`historical_pit` 也不是未見驗證集。擴搜增加了對已知行情的試探次數，較高回測值不能證明未來超額報酬。

上一輪 `d0034` 在官方事後池有 10 筆模擬成交超過該股票當日總成交量，最高成交量參與率約 16.12 倍。官方文件未定成交量上限，所以這不是已判定違規；但均價成交回測沒有滑價與市場衝擊，不能視為實際可成交收益。本輪應同時報告新獲選者的這兩項容量數字，不以策略報酬遮蓋。

最終只可稱「通過已量測研究門檻」。Active Share、公司行動細節、官方帳本、即時來源與送件接受仍屬未知；正式政策維持 `BLOCK_SUBMISSION`，即使局部擴搜找到更高報酬也是如此。Git 保存研究成果不等於競賽平台接受。
