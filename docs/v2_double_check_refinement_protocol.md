# v2 double-check：第三輪局部細搜規格

本輪只在已稽核的 `x0352` 周圍搜尋研究參數。正式交易入口維持 `BLOCK_SUBMISSION`；Active Share、官方帳本與平台收件等證據缺口，不能靠增加回測消除。逐條規則與未知項目見[規則表](v2_double_check_rules.md)。

## 問題與搜尋範圍

上一輪 `x0352` 在官方事後股票池的帳面總報酬為 309.16%、最大回撤為 22.22%；同一組參數在歷史股票池的報酬為 156.68%。本輪要檢查它是否只是上一輪離散網格中的局部尖峰，尤其上一輪的 `volume_high=2.5` 位於搜尋下界。這些都是已使用過的開發期行情；更高數字不能證明樣本外績效。

固定 `x0352` 的其餘設定，只搜尋以下四軸完整局部網格。81 個位置中，1 個為原 `x0352`；另外 80 個有效設定各在兩個股票池回放，共 160 次新試驗。這只窮舉**本表**的離散組合，不代表所有可能參數。

| 參數軸 | 取值 |
|---|---|
| `momentum_weight` | 0.50、0.55、0.60 |
| `long_return_fraction` | 0.15、0.20、0.25 |
| `volume_low` | 0.75、0.80、0.85 |
| `volume_high` | 1.5、2.0、2.5 |

四軸是選股訊號設定，不能放寬官方風控。`volume_low` 和 `volume_high` 是相對成交量的進場過濾，**不是**委託量相對市場成交量的限制。持股檔數、單股權重、現金、整張、白名單、費稅與價格保護沿用已稽核版本。[凍結設定](../config/v2_double_check_refinement.json)列出每個網格位置與候選 ID。

## 完成和選擇條件

先驗證[上一輪獨立稽核](../outputs/v2_double_check_expansion/audit.json)及其雜湊，再與前兩輪全部 1,409 個有效設定去重。新候選 ID 為 `y0000`～`y0079`，舊候選 `x0352` 保留為基準；新輸出放在獨立的 [`outputs/v2_double_check_refinement`](../outputs/v2_double_check_refinement/)，不得覆蓋既有結果。

每個新候選需在兩池完成 417 個交易日，未失格、報酬與風險指標有限，且八項已量測計數逐項為零：`raw_rule_breach_days`、`measured_hard_breach_days`、`no_valid_plan_days`、`unfilled_orders`、`simulated_warning_days`、`stale_held_price_days`、`hold_without_envelope_days`、`execution_price_bound_breaches`。缺值不可當成零。各試驗帳本須獨立核對；失敗、中斷或未通過稽核者不得參與選擇。

僅以 `official_ex_post` 的合格候選與已稽核 `x0352` 排序，依序比較帳面 NAV 總報酬（高者優先）、最大回撤、雙邊換手率、ID。若無新候選勝出，保留 `x0352` 並記錄「未更新」。獲選參數原樣重播 `historical_pit`，該池只作敏感度檢查。最終需驗證設定與來源雜湊、160 次試驗完整性、逐試驗帳本、勝出者兩池重播，以及摘要與原始帳本一致。

## 結果限制

2025-01-02～2026-09-21 的兩池行情均已參與開發；`official_ex_post` 將 2026 年公布的股票池用於 2025 年，含成分股前視偏誤。歷史池也不是未見驗證集。本輪多次試探可能放大開發期選擇偏誤。

均價成交模型沒有滑價與市場衝擊。原 `x0352` 在官方事後池有 13 筆模擬成交超過該股票當日總成交量，最大參與率約 7.07 倍；新獲選者也須報告這兩項容量數字。這不是已確認的官方違規，但不能將帳面收益當作可實際成交收益。

最終結果只可稱「通過已量測研究門檻」。Active Share、公司行動細節、官方帳本、即時來源與送件接受仍屬未知；正式政策維持 `BLOCK_SUBMISSION`。Git 保存研究成果不等於平台接受。
