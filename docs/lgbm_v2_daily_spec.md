# LightGBM-v2 每日排名 spec

一次回答：每天都用 LightGBM-v2 排名（完全取代 Mom20），是否比 Mom20 好？

- Production 不動，仍是 Mom20；只在分支 `claude/lgbm-v2-daily` 研究
- 規則在看到結果前寫死於本文件；評估只跑一次，FAIL 就停止
- 凍結日期：2026-09-25

## 1. 策略

```text
每個決策日 D：D−1 特徵 → LightGBM-v2 預測 → 排名 → 共用組合層、Active Share、planner、D-Plan
```

- 沒有 gate，每天都用 LightGBM-v2
- 可排名的股票與 Mom20 相同：近 20 日每天都可交易
- 組合層與 production 相同
  - 前 25 檔等權，投入 95%
  - 續抱區 35 名，換手門檻 10%
  - 最後 3 天不交易
- 某天沒有預測就報錯，不改用 Mom20

## 2. 模型：只有 v2-A

完全沿用 [docs/hybrid_spec.md](hybrid_spec.md)：

- 特徵：第 5 節全部（v2-A），不含原始價格
- 資料與可用時間：第 3、4 節（2014 起；月營收次月 11 日起，法人當日盤後）
- 標籤與訓練：第 6 節
  - 未來 10 日原始報酬，學習率 0.005，Pearson 提早停止
  - C 方式：選好樹數後用 100% 資料重訓
  - 全域日曆上每 5 個交易日重訓，只用重訓日前一日以前已確定的標籤

唯一差別：每個交易日都需要預測，不只 panic 日。

## 3. 期間

| 期間 | 用途 |
|---|---|
| 2014 | 暖身 |
| 2015–2024 | 歷史評估，只跑一次 |
| 2025–2026/09 | 純測試：評估 PASS 後才跑，只跑一次，只報告 |

- 窗口：24 交易日，每月月初、月中起點（2015–2021 dev、2022–2024 validation）
- 與 Mom20 在同一組窗口逐窗口配對

### 揭露：2015–2024 是第二次使用

- 模型沒有偷看答案：每個預測都只用當時以前的資料
- 但這段期間已經在 Hybrid 評估用過
  - LightGBM-v2 在 panic 日（約 23% 的日子）的表現已被看過
  - 同一段資料比較第二種用法，數字可能稍微偏樂觀
- 因此決定性的證據是 2025–2026 純測試：LightGBM-v2 從未在該段期間被評估

## 4. 通過條件

`Δ = R(LightGBM-v2 每日) − R(Mom20)`，逐窗口配對：

| 條件 | 門檻 |
|---|---|
| 配對平均 Δ | > +0.5% |
| 配對中位數 Δ | ≥ 0 |
| 取消資格 | 不多於 Mom20 |
| 成本 | LightGBM-v2 成本 − Mom20 成本 < 平均 Δ |

| 結果 | 動作 |
|---|---|
| 全部通過 | PASS → 跑 2025–2026 純測試一次 |
| 任一不通過 | STOP，維持 Mom20 |

- 不調特徵、不調組合參數、不換標籤
- FAIL 後不再改用法重試

## 5. PASS 之後

1. 2025–2026/09 純測試一次，只報告
2. 純測試也維持優勢，才討論 shadow 與是否升 production

## 6. 已知風險（事先寫下，不放寬判定）

- LightGBM 的周轉一直高於 Mom20
  - 第一版約 6，Mom20 約 3.4
  - Hybrid 從 3.7 升到 5.1
- 多付的成本可能吃掉優勢，照第 4 節成本條件判定
