# Fintune v2：整理後版本

日常只使用 `fintune_v2.py`。它是原固定入口 `v2_offcial_best_deep_tuning.py` 的薄包裝，保留原有參數、計算、時序與禁止提交條件，不改變策略。

## 保留什麼

| 範圍 | 用途 |
|---|---|
| official_docs 全部 | 比賽原始依據 |
| daily_auto | 產單、驗證、對帳 |
| src 與共用 scripts | 固定回放與稽核依賴 |
| 凍結 config、data | 同版本重現 |
| 最終報告、PPT | 獲選結果与比較 |
| 可信度稽核 | 偏誤與事件限制 |
| 最終帳本、810 列摘要 | 追溯與比較 |

`docs` 保留官方規則稽核、本輪協定、目前所用資料及規劃器說明。舊策略提案、舊輪次報告、v3、A/B/C 獨立入口已移除。

舊名稱模組仍可能被固定回放或獨立稽核引用。它們不是新的策略選項。雜湊綁定的程式與輸入保留原位元組，避免為了整理而失去原研究對照。

## 使用界線

此處的最佳配置是全期開發資料上的獲選配置，不是未見資料冠軍。公司事件、Active Share 和正式回執等缺口仍存在，詳見可信度稽核。整理沒有修正或抹除這些限制。

`requirements.txt` 固定本機驗證的 Python 套件版本。新的回放請用未存在的輸出目錄；不能覆寫凍結結果。
