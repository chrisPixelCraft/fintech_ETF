# A 策略深入調參｜實驗規格

本輪問題：固定第二輪交易與規則執行器後，擴大 A 的有效參數搜尋，能否改善扣成本報酬，並找到回撤不高於既有 A 的候選？

主要比較是 A 對自己的已稽核版本。B／C 不再調參；固定 v1／0050 只作版本參考，不能從不等的搜尋預算推論 A 在方法上必然較好。

## 基準與資料

- 歷史股票池基準：第二輪 A p052，報酬 192.21%、economic MDD 23.67%。
- 正式名單事後基準：第二輪 A p049，報酬 277.51%、economic MDD 25.36%。
- 期間：2025-01-02 至 2026-09-21，417 個交易日、本金 10 億元。9/22 11:50 尚未收盤，不能加入當日完整 VWAP。
- 歷史池保留 2024 年底可知時點的重建假設。正式 150 檔池保留真實 2026 年公布時點，僅作有成分股前視偏誤的事後情境。
- 兩軌原始行情、公司事件、費稅、股息帳務、指標暖機與 4H 資料均沿用已稽核凍結版本。
- 所有期間已參與先前開發。這輪不是未見樣本外測試，事後選參本身有過擬合風險。

## 變數角色

| 角色 | 內容 | 本輪處理 |
|---|---|---|
| 科學比較 | 4H 方向確認是否有用 | 每組 Sobol 參數配對 strict／coverage_only，兩模式相同搜尋預算 |
| 可調配套 | 目標持股、換股、趨勢窗口、評分、風險與量能閾值 | 單軸探測、廣搜、局部調整；聯合候選不作單因子歸因 |
| 條件參數 | 普通换股分差 | 普通換股上限為 0 時不生效，按有效設定去重 |
| 固定項 | 競賽硬限制、均價成交、費稅、整張與價格預算、現金 guard、資料 | 不為績效放寬 |
| 排除項 | 板塊／美股權重 | A 不使用，不浪費候選數 |

數值窗口直接寫入設定，避免只在 fast／base／slow 三個名稱間切換。日線長期 EMA 100／200、200 日暖機、4H EMA20／MACD12/26/9／50 根棒保持固定；結論只適用此範圍。

## 預先指定的搜尋

1. **探索 201 組／股票池**：兩個已知 A 基準、71 組單軸探測、128 組配對 Sobol。
2. **Sobol**：兩個 seed（20260922、20260923）各 32 組有效配套；每組各跑 strict 與 coverage_only，共 64 對。
3. **局部深化 64 組／股票池**：從每種 4H 模式的合格報酬前二、回撤受限最佳中選父組。每次調整 1–3 個相鄰參數；可於預先列出的邊界延伸值探測。
4. **總計 265 組／股票池、530 組正式回測**。另有四次轉接器工程 smoke，不混入正式候選。完整設定位於 `config/a_deep_study.json`。

局部候選由整段歷史的探索結果產生，屬 adaptive full-development search。保留父組、生成 seed、探索結果雜湊及完整候選。不把局部候選事後放進歷史選參，宣稱當時可知。

本輪有明確有限預算，沒有窮舉全部參數組合。若最佳仍落在合理邊界，報告標示搜尋未飽和，不聲稱全域最佳。

## 硬規則與選擇

股票持有 20–30 檔、一般股上限 10%、台積電 25%、現金非負且嚴格小於 25%；白名單按各情境獨立檢查。現金 guard 固定 12%、headroom 2%；價格壓力上下界 0.9／1.1、整張 1,000 股、手續費 0.1425%、賣出稅 0.3%。全部採前期資料決策、次日固定股數 VWAP 成交。只允許事前持有現金可預付的跨股同日買賣。

- **報酬最佳**：全期零已量測硬性違規，然後依扣成本總報酬、較低 MDD、候選 ID 排序。
- **回撤受限最佳**：同上，另要求 MDD 不高於同情境的既有 A。這是另列選項，不偷偷替換主要目標。
- **strict 最佳**：同一零違規門檻，但限定要求 4H 偏多方向。
- 無合格候選：`NO_ELIGIBLE_WINNER`，不得退而選最少違規者。
- Active Share 仍無可驗證歷史 ETF 持倉，維持 UNKNOWN／BLOCK_SUBMISSION。工程完成不等於正式比賽合規；零股殘額及正式提交一致性等未認證項目沿用第二輪限制。

## 診斷與判讀

報酬、economic／帳面 MDD、月報、換手、費稅、交易日、現金範圍、違規與不可行執行日一起呈現。分段檢查 2025 上／下半年、2026 上半年與第三季截至 9/21，不把它們稱為新測試集。

檢查單軸效果、搜尋邊界、4H 成對差異、兩個 Sobol seed 的搜尋最佳差異。相同凍結設定屬確定性回測，不浪費預算換隨機 seed 重複同一交易；以工程精確重播驗證確定性。區塊 bootstrap 如提供，只是對固定已選曲線的條件診斷，不校正選擇偏誤，亦不是未來報酬保證。

狀態：研究候選可依零量測違規與重播驗證交付；正式採用始終 HOLD，直到 Active Share 等完整認證及後續未參與開發資料足夠。

## 執行與驗證

新檔案隔離，第二輪所有凍結檔與最佳程式保持原狀。無 Git 儲存庫，改以程式／設定／資料 SHA-256、環境、命令、PID、逐組 receipt、狀態與來源快照保存。每組完整交易日期相同，不用提前停止替換全期比較。

正式執行前：任意數值指標手算對照、未來資料擾動／截斷測試、兩軌真實基準精確重播、硬限制防改測試。執行後：獨立重建所有候選帳務與選優、最終完整帳本、月表及圖表。

Tuning Playbook 提供研究設計原則，不是金融有效性的證據。本輪採用的是變數分類、配對預算、探索後深化、邊界檢查與保守採用規則。
