# v2 double-check：第四輪結構參數搜尋規格

本輪以已稽核的 `x0352` 為基準，檢查持股數、現金緩衝與兩組訊號期間的交互作用。前三輪在相同開發期資料上反覆選參，第三輪 80 組新設定未勝過 `x0352`；更高的回測報酬仍不能證明未來績效。正式入口維持 `BLOCK_SUBMISSION`，規則與未知項目見[規則表](v2_double_check_rules.md)。

## 研究問題與凍結網格

**問題：** `x0352` 的結果是否依賴目前 20 檔持股、12% 現金緩衝與 10/30 日訊號期間？**預測：** 增加持股數可能降低單筆委託相對成交量，但也可能稀釋訊號；調整現金緩衝及期間可能改變現金違規、換手與回撤。最強替代解釋是已看過行情上的多重試探噪音；因此本輪只比較開發期可行性，不推論樣本外收益。

固定 `x0352` 其餘所有設定，窮舉下表四軸的 81 個離散位置。成對改動報酬與 EMA 期間，避免產生未預先宣告的快慢窗組合。

| 參數軸 | 取值 |
|---|---|
| `target_count` | 20、25、30 |
| `cash_guard_ratio` | 0.08、0.12、0.16 |
| `return_pair`（短、長日數） | (5, 20)、(10, 30)、(15, 40) |
| `ema_pair`（快、慢日數） | (5, 20)、(10, 30)、(15, 40) |

四軸值均在第一輪已宣告的搜尋空間。持股 20–30 檔與現金低於 25% 的官方條件不因目標值而自動滿足，必須逐日重驗。使用與前三輪相同的引擎、資料、費稅、價格保護和八項已量測門檻；不調整規則以迎合結果。[凍結設定](../config/v2_double_check_structural.json)列出每個位置、完整參數及來源候選。

## 執行與決策規則

先驗證[第三輪獨立稽核](../outputs/v2_double_check_refinement/audit.json)及父代帳本，再與前三輪全部 1,489 個不同設定去重。預先計算的 81 個位置中，只有 `x0352` 已測；新增候選 `z0000`～`z0079` 各在 `official_ex_post`、`historical_pit` 回放 417 個交易日，合計 160 次新試驗。輸出隔離在 [`outputs/v2_double_check_structural`](../outputs/v2_double_check_structural/)，不覆蓋已稽核結果。

僅完整、帳本獨立核對通過、有限指標且八項計數均為零者可參與排序：`raw_rule_breach_days`、`measured_hard_breach_days`、`no_valid_plan_days`、`unfilled_orders`、`simulated_warning_days`、`stale_held_price_days`、`hold_without_envelope_days`、`execution_price_bound_breaches`。缺值不能當作零。失敗、中斷或未通過獨立稽核的輸出隔離，不進表格或結論。

只在 `official_ex_post` 將合格新候選與已稽核 `x0352` 比較，依序排序帳面 NAV 總報酬（高者優先）、最大回撤、雙邊換手率、ID。若沒有新候選勝出，沿用 `x0352`。獲選的單一參數組原樣在 `historical_pit` 重播，僅作敏感度檢查。結束條件是 160 次新試驗和勝出者兩池帳本完整、來源雜湊一致，獨立稽核重算並通過，且研究報告與 README 使用相同經驗證數字。不得宣稱已搜尋所有可能參數。

## 解讀邊界

兩池 2025-01-02～2026-09-21 行情均已參與開發；`official_ex_post` 將 2026 年公布的名單回套 2025 年，含成分股前視偏誤。歷史池也不是未見測試集。多輪搜尋會放大選擇偏誤，不能把最佳帳面報酬當作未來預測。

模型採均價成交且未納入滑價與市場衝擊。基準 `x0352` 在官方事後池有 13 筆模擬成交超過標的當日總成交量，最大參與率約 7.07 倍；新候選必須另外報告容量限制。這不自動構成已證實的官方違規，但會限制收益可實現性。Active Share、公司行動細節、官方帳本、即時來源及平台送件接受仍缺可核對的官方證據；正式政策一律 `BLOCK_SUBMISSION`。
