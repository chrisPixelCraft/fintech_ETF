# Residual 修正 spec：換基準、產業 residual、β 收縮

一次回答：residual momentum 在 20／25 日和一般動能打平、在 2025–2026 輸，三種修正能否改善？

- **探索性研究**：2015–2026 全部期間都已看過（DEV、validation、final test、H1 test），結果只能當探索性證據
- **Production 不論結果都維持 Mom20**；最多選一個修正進 prospective shadow
- 規則在跑任何修正版策略前寫死於本文件；每個策略每段只跑一次
- 凍結日期：2026-09-25；分支 `claude/h1-residual`

## 0. 背景

- [residual_regimes 報告](../research/results/residual_regimes/summary.md)：resid20 − mom20 全期 −0.07%、resid25 − mom25 +0.01%；2022–2024 小贏（+0.48%／+0.32%），2025–2026 輸（−0.98%／−0.63%）
- 最明顯的格子：Mom20 持股偏向高 β 時 resid25 − mom25 −0.39%（t = −2.2），但幾乎全部來自 2025–2026

## 2. 修正（每個只改一件事，其餘與原 residual 相同）

原 residual：β 為近 60 日 `cov(lr, lm) / var(lm)`，`resid = Σ (lr − β × lm)` 近 N 日，`lm` 為 0050。

| 代號 | 修正 | 公式 |
|---|---|---|
| A `ew` | 市場基準換成 150 檔等權 | `lm_i(t)` = 當天有報酬的其他股票 `lr` 平均（不含股票 i） |
| B `industry` | 產業 residual | `lm_i(t)` = 同產業其他股票的 `lr` 平均；產業成員 < 3 檔時改用 A |
| C `shrink` | β 收縮 | `β* = 0.5 × β + 0.5`，基準仍為 0050 |

- 共同：N = 20、25；β 60 日；視窗至少 80% 有值；空值排名給 0.5；可排名股票與 Mom20 相同
- 只用 D−1 以前的報酬；等權與產業平均都只用當天有報酬的股票
- 組合層與 production 相同：前 25 檔等權、投入 95%、續抱 35 名、換手門檻 10%、最後 3 天不交易
- 不做「residual ÷ 殘差波動」：同樣的想法在一般動能上已測過（`risk_adjusted` −0.83%）

**產業資料**
- 來源：證交所 ISIN 頁面（上市 `strMode=2`、上櫃 `strMode=4`）的「產業別」，2026-09-25 抓取，存 `data/momv2/industry.csv`，原始回應的 sha256 在 `industry_provenance.json`
- 150 檔全部有分類；成員 ≥ 3 檔的產業 12 個，其餘 16 檔用等權市場
- **揭露**：這是現在的分類，套用到 2015 年起會有輕微 look-ahead（例如 2023 年新增的產業類別、公司改分類）

## 3. 事先寫下的預期

| 修正 | 預期 |
|---|---|
| A 等權基準 | 效果有限；第 1 節顯示動能贏家對等權市場的 β 偏向更大，2025–2026 可能不會改善 |
| B 產業 residual | 持股和 Mom20 差最多；方向不確定；若「同產業相對強」才是真正有用的訊號，2022–2024 應該最好 |
| C β 收縮 | 最接近原 residual，差距小 |

## 4. 執行

- 6 個新策略（A、B、C × N 20／25），跑 2015–2021、2022–2024、2025-01 到 2026-09 三段，各一次
- 與 mom20、mom25、resid20、resid25 逐窗口配對（這四個已有結果，同一批 run）

## 5. 報告：一張大表

每個策略一列，欄位：
- 三段與全期的平均報酬
- 對同長度 mom 的配對平均 Δ 與勝率
- 對原 residual 的配對平均 Δ
- 周轉、成本、最差窗口
- 「Mom20 持股偏高 β」那組窗口的 Δ

另外逐一對照第 3 節的預期。

## 6. 判定（只決定是否進 shadow）

修正版進 shadow 必須同時滿足：

1. 全期 276 窗口，對同長度 mom 的配對平均 Δ > 0
2. 三段中沒有任何一段的平均 Δ（對同長度 mom）< −0.5%
3. 2025–2026 的平均 Δ（對同長度 mom）比同長度的原 residual 好

- 多個符合時，選全期平均 Δ 最高的一個
- 都不符合：residual 研究結案
- 通過也不改 production；shadow 另開工作
