# 規則與正式使用限制

**目前是研究回放，正式提交維持 `BLOCK_SUBMISSION`。** 原始依據保留於 [official_docs](../official_docs/)，未取得的主辦方證據不會被當作通過。

## 回放中檢查的條件

| 項目 | 固定條件 |
|---|---|
| 初始本金 | TWD 10 億 |
| 持股檔數 | 20–30 |
| 一般單股上限 | NAV 10% |
| 台積電上限 | NAV 25% |
| 現金比例 | ≥0 且 <25% |
| 委託單位 | 1,000 股 |
| 買賣手續費 | 0.1425% |
| 賣出稅 | 0.3% |
| 訊號與定股數 | 前日已知資料 |
| 模擬成交 | 次交易日均價 |

全期帳面 NAV 與股利歸屬後的 `economic_nav` 分開保留。年度比較採後者；309.16% 對齊原全期帳面報酬。帳本模擬整日違規回退、警告累積及三次失格，也追蹤主動／被動超限。候選資格另要求原始超限日為零，不依賴被動超限寬限。

±10% 價格保護是額外研究門檻，並非官方保證。未成交、缺報價、無有效交易計畫或超出價格保護，都會使窗口未通過研究資格；不能把它們全部解讀成官方警告。

## 仍缺的官方證據

Active Share 尚缺逐日 ETF 持股、發布時間與算法確認；公司行動、零股、費用取整及警告回退順序仍有平台契約缺口。主辦方帳本、正式收件、策略一致性及行政資格，也無法由歷史回測證明。

因此 `plan` 與 `research-plan` 都不輸出可提交政策。零回測警告只支持指定輸入上的已量測門檻，不代表比賽完全合規；到了正式賽期，缺少送件本身也可能違規。

完整歷史逐條核對見[整理前規則表](https://github.com/chrisPixelCraft/fintech_ETF/blob/d613b75/docs/v2_double_check_rules.md)。原始文件與現有程式不代表已確認最新平台公告。
